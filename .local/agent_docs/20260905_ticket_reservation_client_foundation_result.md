# チケット予約共通クライアント基盤 実装結果

## 実装結果

- 公開イベント取得、予約作成、管理者キャンセルのSupabase呼び出しを共通関数へ整理した。
- `datetime-local` と保存ISO日時の変換、受付境界、予約可能枚数の計算を共通化した。
- request ID付きcanonical予約RPCを呼び出し、任意の備考は未指定時も `null` を明示送信する。
- 公開イベント取得後の可用性RPCを権威ある予約枠スナップショットとして扱い、RPC結果に存在しない枠は初回埋め込み結果から除外する。
- 終了境界ちょうどでも一度タイマー再評価対象に残し、DB側の境界条件を変えずに表示が受付中のまま残る問題を防いだ。
- `windows:ticket_windows(*)` の埋め込みに対する並べ替え指定を alias `windows` に統一し、PostgRESTの埋め込み修飾子と一致させた。
- 境界時刻ちょうどの挙動をテストへ追加した。

## レビュー対応

- note自体は公開予約フォームの任意項目として維持し、canonical RPC化後も未指定値がfunction解決から落ちないよう `null` を明示送信する。
- イベント埋め込み取得と可用性RPCの間に枠が削除されるraceでは、可用性結果にない枠を公開画面へ残さないようにした。
- 受付終了境界の再評価問題は、DB契約に合わせてタイマー側を修正した。
- 公開イベント取得の埋め込みalias不一致を修正した。

## 検証

- Node標準テストとGitHub Actions CIで継続検証する。
- 共通クライアント層にUI固有状態を持ち込んでいないことを確認する。
