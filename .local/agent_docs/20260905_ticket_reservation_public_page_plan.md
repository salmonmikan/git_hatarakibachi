# 公開チケット予約ページ 実装計画

## 対象

- `/tickets/:slug` の公開予約ページを追加する。
- 公開イベント、予約枠、残数を取得し、受付期間・開始済み枠・満席状態を画面へ反映する。
- request IDを保持して通信失敗時の冪等再送を可能にする。
- 予約成功後は予約番号を確実に表示し、残数再取得失敗と予約成功を区別する。

## レビュー対応方針

- 予約RPCが成功してレスポンスだけ失敗した場合、受付境界を越えても同一request IDの再送を許可する。
- 予約成功後の公開データ再取得が `data: null` でも、予約番号と完了表示を維持する。
- 入力内容は再送時に変更させず、同一request IDと同一payloadの関係を保つ。

## 確認方針

- ESLint、Vite build、Node標準テスト、GitHub Actions CIを確認する。
- 公開ページの受付可否とDB側の予約制約が矛盾しないことを確認する。
