# 公開チケット予約ページ 実装結果

## 実装結果

- `/tickets/:slug` の公開予約ページを追加した。
- 公開イベント、予約枠、残数を取得し、受付期間・満席・開始済み枠に応じて選択可否を制御した。
- request IDを保持して予約RPCの冪等再送を可能にした。
- 予約RPC成功後にレスポンス取得だけ失敗した場合、受付終了や枠開始後でも保持済みrequest IDによる再送だけを許可した。
- 予約成功後の再取得がエラーまたは `data: null` の場合も、現在のイベントと予約番号表示を維持するようにした。
- 受付終了後は入力欄と予約枠選択を編集不可のままにし、再送時のpayloadとrequest IDを変えないようにした。
- 次の予約入力または新しいrequest IDでの送信開始時に前回の予約番号表示をクリアし、失敗した新規予約と過去の成功表示が同時に出ないようにした。
- 公開イベント取得は共通helper側で埋め込みalias `windows` を使って予約枠を並べ替える。

## レビュー対応

- 受付境界後の冪等再送と、成功後再取得 `data: null` 時の予約完了表示維持に対応した。
- 冪等再送待ち中の予約枠変更を防ぎ、次の予約開始時に以前の予約番号を消すよう修正した。
- 親StackのDB・共通クライアント・管理画面のレビュー修正を同期した。

## 検証

- GitHub Actions CIで継続検証する。
- 公開予約ページ固有の挙動と親Stackの差分を分離した状態で維持する。
