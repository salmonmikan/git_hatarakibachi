# チケット予約管理画面 実装計画

## 対象

- 販売ページ、予約枠、予約一覧の管理UIを追加する。
- Sanityの公開済み公演だけを連携候補として扱う。
- 予約枠の定員・残数、販売停止、予約キャンセルを管理する。
- ページング中の作成・保存・再読込失敗でも編集状態を安全に扱う。

## レビュー対応方針

- 埋め込みリソースの並べ替えはselectで公開したaliasを使用する。
- 販売ページ保存中は一覧の選択・ページ移動を止め、非同期完了で別ページの編集状態を巻き戻さない。
- 予約枠insert成功後に再読込だけ失敗した場合は、追加済みであることを明示して重複再登録を避ける。
- Sanity取得失敗時も既存連携IDを保持する。

## 確認方針

- ESLint、Vite build、Node標準テスト、GitHub Actions CIを確認する。
- 既存の管理画面UI方針を維持し、機能修正に限定する。
